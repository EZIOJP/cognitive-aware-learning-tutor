## [[Exploratory Data Analysis (EDA)]]

*   **Definition:** EDA is a critical initial step in data analysis, used to understand the underlying structure and patterns within a dataset when specific features or goals are not yet known.
*   **Purpose:** Its primary goal is to analyze data—such as the bank manager loan approval example—to identify important features and relationships before developing predictive models.
*   **Core Libraries for EDA:** Several Python libraries are leveraged to perform comprehensive analysis:
    *   **Pandas/NumPy:** Used for fundamental data manipulation, transformation, and numerical operations (working with pure numbers).
    *   **Matplotlib/Seaborn:** Essential visualization tools used to interpret data visually, leveraging the human ability to process graphical information.
*   **Workflow:** The libraries work together: Pandas handles the raw data structure, NumPy performs calculations on that data, and Matplotlib/Seaborn visualize the results to reveal hidden patterns.
