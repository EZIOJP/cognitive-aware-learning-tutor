## Exploratory Data Analysis (EDA)

*   **Definition and Purpose:** EDA is a crucial initial step in data analysis used when the specific patterns or features of interest are unknown. Its goal is to understand the underlying structure and relationships within the data (e.g., analyzing loan approval criteria).
*   **Core Libraries for EDA:** Performing comprehensive EDA requires leveraging several specialized Python libraries:
    *   **Pandas:** Used primarily for data manipulation, transformation, and handling structured datasets.
    *   **NumPy:** Essential for performing efficient numerical operations on arrays of numbers.
    *   **Matplotlib & Seaborn:** Libraries used for visualization, allowing users to interpret patterns more effectively by utilizing the visual cortex.
*   **Workflow Integration:** These libraries work together: Pandas handles the data structure, NumPy processes the raw numbers, and Matplotlib/Seaborn visualize the resulting insights.
