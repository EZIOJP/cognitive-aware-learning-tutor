# Study-core documentation export

Self-contained pack for **notes → quiz → ReviewCards/FSRS → Daily Learn / Study Loop**.  
For external readers and research AIs (including Google Deep Research).

| File | Role |
|------|------|
| [`01-ARCHITECTURE-AND-STUDY-LOOP.md`](./01-ARCHITECTURE-AND-STUDY-LOOP.md) | Architecture bible, data flow, Study Loop design, code excerpts, backlog |
| [`02-NOTES-QUESTIONS-EXAMPLE.md`](./02-NOTES-QUESTIONS-EXAMPLE.md) | Real note section + matching question JSON + schema / tag stitch |
| [`03-DEEP-RESEARCH-PROMPT.md`](./03-DEEP-RESEARCH-PROMPT.md) | Copy-paste Deep Research prompt (includes condensed appendix) |

**Out of scope for this export:** productivity desktop tracker, distraction gate/blocking, wearables, bible morning ritual, planner hard-block UX.

**How to use with Deep Research:** paste file `03` (enough alone); optionally attach `01` + `02` for fuller grounding. Do not implement Study Loop from this pack alone without the repo plan at `docs/superpowers/plans/2026-09-03-study-loop.md`.
