CALT SelfTracker — Microsoft Edge (Chromium MV3)
================================================

CALT is Edge-only for browser gating. Do not use Zen/Firefox for study browsing.

Install in Microsoft Edge:
1. Start CALT backend (run.bat) so http://127.0.0.1:8000 is up.
2. edge://extensions → Developer mode → Load unpacked
3. Select folder: selftracker-extension/
   Or run: scripts\launch_selftracker_edge.bat

*** REQUIRED AFTER UPDATES (v1.5.13) — RELOAD REQUIRED ***
edge://extensions → Reload on CALT SelfTracker.
Also restart the desktop tracker / backend if it was already running
(so Edge process-kill hardening is loaded).
Accept new permissions if prompted.
Keep "Redirect distraction sites while locked" checked in the extension popup.
Tray → Today’s rules should show Mode: BIBLE/STUDY · YouTube blocked.

What it does (v1.5.13):
- Tracks tab URLs/time → ws://localhost:8000/ws/behavior (URL sessions credit study minutes)
- Draggable Jarvis toast on the page + word typewriter (desktop TTS speaks the line separately)
- Light snapshot → POST /api/behavior/browser-telemetry (~45s; idle backoff ~2m)
- Gate poll ~4s: cache + DNR fingerprint ONLY — does NOT query/rewrite all tabs
- Enforce sweep only on ~1 min alarm (or explicit Refresh / toggle redirects)
- softLand only via webNavigation.onCommitted (single committed tab) — not onUpdated
- Circuit breaker: >8 softLands in 30s → pause redirects 2 min (fail soft; Edge stays alive)
- Never tabs.remove cleanup; never windows.update focus storms
- DNR watch hosts capped; rules update only when fingerprint changes
- **Tab-local lock:** blocked site → locked.html (or morning bible/plan SPA) in that tab only
- **Locked screen:** study minutes / goal / time left; same-tab shortcuts (no FOCUS_CALT)
- Explicit FOCUS_CALT / OPEN_PATH still opens/updates one CALT tab when requested (popup)
- Keyword filter on URL + page title only (server block_keywords_list)
- Day modes from server `browser.mode`: bible / planning / study / free
  - After morning plan confirm, daytime default is **study** (not free)
  - Study: allow Scaler/Colab/GitHub/Drive/Gemini/… — does NOT auto-open Scaler; blocks YouTube/Netflix/social
  - Free: shopping/house allowlist; still blocks porn; YouTube only in true free windows
  - bible/planning/study: **youtube.com / youtu.be always forced blocked**
- **Fail-closed:** if gate API is unreachable, last known bible/planning/study mode is kept
- On block → POST /api/behavior/gate-alert → canned Jarvis speak (tracker)
- Popup: mode chip + Jarvis live line; Open Bible/Plan focuses one CALT tab

Desktop tracker: games hard-block; **never kill msedge.exe** (or Edge helpers);
other browsers soft-lock + voice only. Optional ~60s CPU NSFW screen scan when Armed.
Never kills Cursor.
Tray: Free time… (same PIN/phrase as Confirm exit) for temporary free browsing.
